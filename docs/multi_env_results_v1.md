# 多环境结果 v1：Two-Room、ViZDoom、Visual AntMaze（2026-11-14）

接 `min_cost_and_scenarios_v1.md`。三条线并行：Two-Room（官方权重）、ViZDoom（自训世界模型）、Visual AntMaze（自训世界模型）。
术语：min 代价 = 各前缀终点里离目标最近的一个；前缀钳制 = issue #7 的承诺前缀异步规划；整段执行 = 官方方式（执行完 25 步再重规划）。
各 200 回合，延迟按 5 个环境步注入，配对 bootstrap 给出 95% 区间。

## 1. 结论

| 发现 | Push-T | Cube | Two-Room | ViZDoom |
|---|---|---|---|---|
| 官方终点代价在勤重规划下失效 | 是 | 是 | 是（−29.5） | 是（−18.0） |
| min 代价不降成功率、到达更快 | 是 | 是 | 是，静态还 +5.5 | 是 |
| min 代价在目标切换下显著更好 | 是 | 未测 | 是 | 是 |
| 前缀钳制胜过「整段执行 + min」 | 仅目标切换、远目标 | 未测 | 目标切换、远目标 | 静态和目标切换都胜 |

- ViZDoom 是第一个前缀钳制在**静态任务**上也显著胜出的环境（+8.0 [+1.0, +14.5]）。那里停顿有代价：同为整段执行，加 5 步延迟后成功率从 53.0% 掉到 40.5%。
- Visual AntMaze 的数据对齐问题已解决（MuJoCo 版本），但规划本身不可行：成功率 2–6%，对所有方法没有区分度。

## 3. ViZDoom（my_way_home 地图，目标图导航）

## 4. Visual AntMaze（OGBench visual-antmaze-medium-navigate-v0）

### 4.1 数据集对齐

现象：从数据集状态出发按数据集动作重放，位置对不上记录。排查结果：

- OGBench 采集脚本（`data_gen_scripts/generate_locomaze.py`）存的动作就是「专家动作 + N(0, 0.2) 噪声再裁剪到 [−1, 1]」后实际执行的动作，
  `qpos / qvel` 是执行前的状态。数据集自洽，重放应当精确复现。
- 根因是 MuJoCo 版本。300 个起点的重放误差（中位数）：

| MuJoCo | 单步 qpos 最大误差 | 25 步后 xy 误差 |
|---|---:|---:|
| 3.1.6 / 3.2.3 / 3.2.7 / 3.3.0 / 3.4.0 | 3.5e-7 | 约 5e-7 |
| 3.5.0 / 3.6.0 | 8.5e-3 | 0.44 |

  25 步真实位移中位数 2.76。旧版本下的误差就是数据集单精度存储的舍入量级。
- 排除的解释：动作索引错位（用 t−1 或 t+1 的动作单步误差 0.11–0.14）；仿真器内部状态（`mj_resetData` 后结果不变）；
  混沌放大（同一环境起点加 1e-7 扰动，25 步后只发散到 1.4e-6）。
- 做法：AntMaze 用 `.mj/3.3.0`（`PYTHONPATH` 把它放在最前）；Cube / Reacher 仍用 3.6.0。
- 两个版本（`flash_lewm/ant_env.py`）：`FLASH_ANT_NOISE=0` 确定性执行，与数据集记录对齐；`FLASH_ANT_NOISE=0.2` 每步执行动作加同样的噪声并裁剪，与采集条件一致。

### 4.2 规划不可行

世界模型训练 3 万步：验证预测误差 0.05，「画面不变」基线 0.81。但规划冒烟（50 回合，零延迟，成功半径 1.0，75 步内）：

| 配置 | 无噪声 | 带噪声 0.2 |
|---|---:|---:|
| 整段执行，min，CEM 30 轮 | 2% | 2% |
| 整段执行，终点代价，CEM 30 轮 | 4% | 6% |
| 整段执行，min，CEM 100 轮 | 6% | — |
| 每 5 步重规划，min | 4% | — |

判断：CEM 在 8 个关节力矩上（每段计划 200 维）做随机搜索走不出步态，这与用哪种代价、哪种调度无关。没有铺开对照。
要让它可用，需要在高层动作上规划（例如规划行进方向，底层用训练好的步态策略）。

## 5. 局限

- ViZDoom 和 AntMaze 的世界模型是我用精简脚本短训练得到的原型，没有与官方训练流程对比过质量。
- ViZDoom 评估回合的起点和目标来自与训练数据相同的探索策略（不同种子）；成功判据的半径和角度是我定的。
- 各 200 回合，区间半宽约 5–9 个百分点；ViZDoom 只做了静态和目标切换两个场景、一种延迟。
- Reacher 数据和权重已就位，评估没有做。
